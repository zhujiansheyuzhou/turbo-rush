# 05 用户手册

**极速狂飙 Turbo Rush** —— 一款打开浏览器就能玩的 3D 街机赛车游戏

---

## 1. 快速开始

1. 用 **Chrome 或 Edge** 打开游戏目录下的 `index.html`（双击即可，无需安装任何东西）；
2. 点击 **开始游戏**；
3. 选择模式：**竞速赛**（与 3 名 AI 同场竞技）或 **计时赛**（独自挑战纪录）；
4. 选择赛道 → 选择赛车 → 点击 **开赛！**；
5. 倒计时结束后，踩下油门出发！

> 若你的浏览器限制了本地文件访问，可在游戏目录运行
> `python -m http.server 8000`，然后访问 `http://localhost:8000`。

## 2. 操作说明

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 油门 |
| `S` / `↓` | 刹车（停稳后倒车） |
| `A` `D` / `←` `→` | 转向 |
| `空格` | 手刹 —— 配合方向键漂移 |
| `Shift` | 氮气加速 |
| `R` | 重置回赛道中心 |
| `Esc` | 暂停 / 继续 |
| `M` | 静音开关 |

## 3. 游戏模式

### 3.1 竞速赛 🏁
与 3 名 AI 车手（夜枭、闪电、飓风）同场竞技，跑 **3 圈**。
左上角显示实时名次，冲线后按完赛时间排出最终名次。
AI 会超车、会失误、也会在你领先时发力追赶——别掉以轻心。

### 3.2 计时赛 ⏱
赛道属于你一个人，3 圈之内跑出最快单圈。
最佳圈速会保存在本机，下次挑战同一条赛道 + 同一辆赛车时可以冲击自己的纪录。

## 4. 赛车特性

| 赛车 | 定位 | 特点 |
|------|------|------|
| **猎鹰** | 均衡型 | 没有短板，新手首选 |
| **雷霆** | 极速型 | 直线最快，但弯道要提前刹车 |
| **蜂鸟** | 灵活型 | 加速猛、过弯稳，极速略低 |

## 5. 高手技巧

1. **漂移集气**：按住 `空格` + 方向键，车速够快就会进入漂移（后轮冒烟）。漂移时氮气恢复速度是平时的 **4 倍**。
2. **出弯喷射**：漂移出弯、车头回正的瞬间按 `Shift`，把集满的氮气用在直道上。
3. **外内外走线**：入弯前靠外侧，切弯心，出弯放外侧，能带更高的过弯速度。
4. **刹车点**：看到前方红白护墙连续弯曲，提前松油门或点刹车，比撞墙快得多。
5. **雷霆慎用氮气过弯**：氮气只留给直道，弯道里开氮气多半会上墙。

## 6. 常见问题

**Q：没有声音？**
A：浏览器要求先有点击操作才允许播放声音——从菜单点击"开赛"后就会有引擎声。按 `M` 检查是否误触了静音。

**Q：卡在草地上 / 开不动？**
A：草地会大幅减速，按 `R` 可以立即重置回赛道中心。

**Q：为什么过了终点线圈数没变？**
A：计圈需要本圈确实通过过赛道半程点（防止抄近道或重置刷圈）。正常行驶不会遇到。

**Q：计时赛纪录存在哪里？**
A：保存在浏览器的 localStorage 中，清除浏览器数据会同时清除纪录。
