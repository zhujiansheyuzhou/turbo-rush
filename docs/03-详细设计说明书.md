## 1. 车辆物理模块（physics.js）

### 1.1 模型选择
采用**速度分解街机模型**：不模拟轮胎力学，而是把速度沿车身坐标系分解为纵向 `vF` 与侧向 `vL`，分别施加规则。该模型计算量小、参数直观、手感可控，是街机赛车的事实标准做法。

### 1.2 单步算法（伪代码）
```
输入: state(x,z,heading,vF,vL), input(steer,throttle,brake,handbrake,nitro), 参数p, dt, 路面
1. maxSpeed = p.topSpeed × (nitro? p.nitroFactor : 1) × (草地? 0.55 : 1)
2. 世界速度 w = 前向·vF + 右向·vL
3. 纵向驱动: w += 前向 · (油门·accel·(nitro?1.7:1) − 刹车/倒车) · dt
4. 阻力:   w *= (1 − drag·dt)      // drag = 基础0.12 + 松油门0.35 + 手刹0.8 + 草地1.6
5. 转向:   heading += steer · p.steer · 转向权重 · dt · sign(vF)
           // 转向权重 = min(|vF|/10, 1) · (1 − 速度比·p.steerLoss)
           // → 低速转不动、高速衰减、倒车反向
6. 漂移判定: 手刹 ∧ |vF|>12 ∧ |steer|>0.1
7. 用新车头重新分解: vF = w·前向, vL = w·右向
8. 抓地力: vL *= (1 − grip·dt)     // 漂移时用 driftGrip（≈1/5 正常值）→ 侧滑保持
9. 限速: vF ∈ [−reverseMax, maxSpeed]
10. 位置积分: (x,z) += (前向·vF + 右向·vL)·dt
```

**设计要点**：漂移不是特殊状态机，而是"抓地力被人为调低后，第 7~8 步自然产生的侧滑"——甩尾、回正、惯性滑行全部自然涌现，无需硬编码。

### 1.3 参数表（config.js）
| 参数 | 猎鹰 | 雷霆 | 蜂鸟 |
|------|------|------|------|
| topSpeed (m/s) | 60 | 68 | 52 |
| accel (m/s²) | 17 | 14.5 | 20 |

## 2. 赛道数学模块（trackdata.js）

### 2.1 赛道表示
赛道由若干控制点定义，用**向心参数化闭合 Catmull-Rom 样条**插值成中心线，再按弧长等距离散为 600 个采样点。每个采样点预计算切线、右法线、曲率、累计弧长。

> 向心（centripetal）参数化可避免急弯处样条打圈/过冲，是赛道曲线的安全选择。

### 2.2 曲率计算（两遍法）
```
第一遍: tangent[i] = normalize(pos[i+1] − pos[i−1])     // 中心差分
第二遍: kappa[i]  = |tangent[i+1] − tangent[i−1]| / arc(i−1→i+1)
```
> **教训**：必须等所有切线算完再算曲率。初版单遍计算时用到了尚未初始化的下游切线，导致曲率虚高 10 倍、AI 全场龟速——该缺陷由无头仿真测试暴露（见《04 测试计划与报告》Bug-01）。

### 2.3 进度反查（世界坐标 → 进度）
```
query(x, z, lastIdx):
  在 [lastIdx−12, lastIdx+48] 窗口内找最近采样点 best   // 前进方向偏置
  向线段 [best, best+1] 投影得亚采样精度 u01
  lateral = (p − 投影点) · 右法线                        // 右为正
```
- 窗口化使单次查询 O(61) 而非 O(600)，且防止"抄近道跨弯"时进度跳变；
- `lateral` 同时服务于：出界判定（|lateral| > 半宽）、护墙碰撞（|lateral| > 半宽+1.6）、AI 车道保持。

## 3. AI 模块（ai.js）—— Pure Pursuit 纯追踪

```
compute(state, params, u01, rubber, nitro, dt):
  1. 预瞄距离 look = clamp(10 + |vF|·0.5, 12, 42)         // 速度越快看得越远
  2. 预瞄点 = 中心线(u01 + look/全长) + 右法线·(车道偏移 + 0.8·sin(摆动))
  3. steer = clamp(夹角(车头, 预瞄点)·2.4, −1, 1)
  4. 前方曲率 κ = maxCurvature(u01+0.004, u01+1.6·look/全长)
  5. 弯道安全速度 vCorner = √(aiLat·skill / κ)
  6. vTarget = clamp(vCorner, 16, topSpeed·skill·rubber)
     vF < vTarget−1 → 全油门；vF > vTarget+2 → 按超出比例刹车
  7. 急弯(vCorner<24)且车速>30且夹角大 → 手刹甩尾
  8. κ<0.008（长直道）且 nitro>55 → 开氮气
```

**橡皮筋机制**：`rubber = clamp(1 + (玩家进度 − AI进度)·0.9, 0.88, 1.12)`，落后提速、领先放水，保证比赛全程有悬念（FR 隐含体验需求）。三名 AI 水平系数 0.93~1.01 递增，形成自然梯度。

## 4. 比赛核心模块（racecore.js）

### 4.1 圈数判定（防作弊）
```
每帧: du = u01 − frac(progressTotal)，规范到 (−0.5, 0.5]
progressTotal += du
frac ∈ (0.45, 0.60) → canCountLap = true               // 通过半程点
跨整数圈 且 canCountLap → 计圈、记录圈速、重置标记
跨整数圈 但 !canCountLap → 不计圈，进度回退到 lap+0.999
按 R 重置 → canCountLap = false                        // 防"重置刷圈"
```

### 4.2 名次判定
排序键：已完赛者按 finishTime 升序；未完赛者按 progressTotal 降序；完赛者优先于未完赛者。

### 4.3 碰撞
- **护墙**：|lateral| 超限 → 位置钳回墙边，外侧速度分量反弹 25%，纵速 ×0.82，速度>12 时发 `wall` 事件；
- **车际**：圆形模型（半径和 3.3m）重叠 → 沿连心线各推开一半，纵向速度互相渗透 25%，发 `bump` 事件。

### 4.4 氮气资源
使用：−32/s；恢复：+5/s，漂移时 +20/s。初始 70。AI 仅在直道使用（见 3.8）。

## 5. 表现层关键设计

### 5.1 赛道场景生成（track.js）
| 元素 | 做法 |
|------|------|
| 路面 | 沿采样点向两侧扩展半宽生成三角带；Canvas 程序化沥青贴图（噪点+白边线+黄虚线），UV.y 按弧长平铺 |
| 护墙 | 中心线 ±(半宽+1.6) 处竖直三角带，红白条纹贴图 |
| 起点线 | 棋盘格贴图面片，按切线定向 |
| 龙门架 | 双立柱 + 横梁盒体 |
| 草地 | 2400×2400 平面，噪点绿草贴图 60× 平铺 |
| 树木 | 随机 u、随机侧、路外 6~51m，共享圆柱+双圆锥几何，随机缩放旋转 |

### 5.2 车模与特效（car.js）
- 盒体拼装：车身/座舱/尾翼/前后车灯 + 4 轮（前轮枢轴随 `steer·0.42` 偏摆，全轮按 `vF·dt/r` 滚动）；
- 漂移时车身附加 −steer·0.04 侧倾（指数平滑）；
- 烟雾：26 个 Sprite 对象池，漂移/草地打滑时以 40 个/秒在后轮处生成，上升扩散淡出；
- 氮气火焰：加色混合 Sprite，随机缩放闪烁；
- 阴影：径向渐变半透明面片（假阴影，零阴影贴图开销）。

### 5.3 追逐相机（game.js）
```
目标位置 = 车尾 − 前向·(8.5 + 0.06·speed) + 上·(3.4 + 0.012·speed)
位置用 damp(λ=6) 指数平滑；注视点 = 车头前方 7m
撞墙 → camShake 0.35s 随机抖动
氮气 → FOV 62→74 平滑过渡（速度感）
```

### 5.4 音效合成（audio.js）
- 引擎：锯齿波 → 低通 → 增益；频率 = 55 + 165·速度比 (+40 氮气)，滤波截止随速度抬高；
- 倒计时/GO：方波短促哔声 440/880Hz；
- 碰撞：衰减白噪声经 500Hz 低通；
- 遵守浏览器自动播放策略：在"开赛"按钮的点击手势中创建 AudioContext。

## 6. 界面流与 DOM 契约
index.html 中固定 ID 契约（菜单/HUD/结算/暂停），JS 按 ID 绑定；界面样式集中在 css/style.css。菜单流转：title → mode → track → car →（hideAll）→ HUD；赛道预览在进入 track 界面时用 TrackData 采样点绘制到卡片 canvas。

## 7. 可测试性设计
- 逻辑层六个文件（utils/config/trackdata/physics/ai/racecore）无任何 DOM/BOM 依赖（仅 window 命名空间与 THREE 数学类）；
- test/sim.js 在 Node 中以 `window=global` 加载 same 源码，`AIDriver` 扮演玩家注入输入，全速仿真整场比赛——**测试与生产运行同一份代码**，无重复实现。
